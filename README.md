# Hi there 👋

I'm an application security engineer. I build security into every stage of the software development lifecycle, from threat modeling at design time to automated scanning in CI/CD and incident response in production.

- 🔐 Focused on application security, mostly in fintech and enterprise software
- 🛠️ I like building the tooling that makes security scale: custom SAST rules, DAST automation, vulnerability pipelines and scoring
- 🤝 I enjoy training developers and security champions

## What I work on

| Area | Tools and methods |
|------|-------------------|
| Secure SDLC | Shift-left and shift-right controls, security standards, security champions programs |
| Security testing | Semgrep, Fortify, Checkmarx, Burp Suite, ZAP, MobSF, manual penetration testing |
| Threat modeling | STRIDE, risk-based assessment, OWASP Top 10, OWASP ASVS |
| Vulnerability management | DefectDojo, Tenable, SBOM and container scanning |
| Cloud and edge | Cloud-native security, Cloudflare, WAF tuning |
| Operations and compliance | SIEM integration, incident response playbooks, PCI-DSS |
